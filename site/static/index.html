> SELECT POWER-UP

EVERYTHING UNLOCKED

Everything Hazelcast Community Edition does (distributed maps, caches, queues, SQL, stream processing with Jet), plus open-source implementations of the features Hazelcast sells only in its Enterprise Edition.

TLS & SECURITY

Encrypted member, client and WAN connections. JAAS realms, client certificates and client permissions.

CP SUBSYSTEM

Raft-based linearizable locks, atomics, semaphores, latches and CPMap.

HIGH-DENSITY

Data off the Java heap, managed with the FFM API. Big heaps, small GC pauses.

PERSISTENCE

Data and cluster metadata on disk, coordinated cluster restart and hot backups.

WAN REPLICATION

Asynchronous replication of maps and caches between clusters and regions.

BLUE/GREEN

Client failover between clusters for zero-downtime cut-overs.

YOUR CLIENTS WORK

Official Hazelcast clients for Java, Python, Node.js, Go and .NET connect to Hecaton clusters.

FREE PLAY

No license key, no node limits. Kubernetes discovery built in.

> LEVEL SELECT

QUICK START

Members run on Java 25; client applications on Java 17 or later. On one network, members find each other by multicast.

LEVEL 1

CONTAINER

One member, one command.

docker run -p 5701:5701 \
  ghcr.io/l0ngsight/hecaton:<version>
LEVEL 2

DISTRIBUTION

From the GitHub releases.

tar xzf hecaton-<version>.tar.gz
cd hecaton-<version>
bin/hc start
LEVEL 3

EMBEDDED

Depend on uk.org.hecaton:hecaton-member.

HecatonInstance member =
    Hecaton.newHecatonInstance();
IMap<String, String> map =
    member.getMap("scores");

> SAVE FILES

CONFIG SCHEMAS

XML Schemas for member, client and Spring configuration, so your IDE can validate and autocomplete hecaton.xml. JSON Schemas for YAML configuration are next to them.

  • MEMBERhttps://hecaton.org.uk/schema/config
  • CLIENT & FAILOVERhttps://hecaton.org.uk/schema/client-config
  • SPRINGhttps://hecaton.org.uk/schema/spring
hecaton.xml
<hecaton xmlns="https://hecaton.org.uk/schema/config"
  xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xsi:schemaLocation="https://hecaton.org.uk/schema/config
    https://hecaton.org.uk/schema/config/hecaton-config-5.7.xsd">

  <cluster-name>dev</cluster-name>
  <map name="scores">
    <backup-count>1</backup-count>
  </map>
</hecaton>

CONTINUE?

Coming from Hazelcast? An OpenRewrite recipe moves your Java code and builds to Hecaton, and hecaton-migrate converts configuration, Dockerfiles, Kubernetes manifests and scripts. A data copier moves live map entries between clusters.
